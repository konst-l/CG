Лабораторная работа 2, вариант 6.
Требуется: Python 3.8+, numpy, Pillow (pip install numpy pillow). tkinter входит в стандартную установку Python.

lab2_app.py              - приложение (python lab2_app.py)
image_ops.py             - алгоритмы (поэлементные операции, линейное контрастирование, Оцу, треугольник)
make_test_images.py      - создаёт базу test_images/ и эталонные маски test_images/masks/
make_report_figures.py   - создаёт иллюстрации и таблицу результатов для отчёта (report_figures/)

Светлый/тёмный объект на тестовых изображениях:
  02, 07, 09 - светлые объекты на тёмном фоне; 01, 03, 04, 05, 06, 08 - тёмные объекты на светлом фоне.
